    Security

    Powerful, and on a short leash.

    Agents only touch what you allow, and every action is recorded.

    • Scoped permissions. Read-only by default, write access per tool.
    • Human approval. Sensitive steps always wait for a person.
    • Full audit trail. Every step, input and result, searchable.
    • Your data stays yours. Never used to train shared models.

    FAQ

    Questions, answered.

    Does the agent act without asking?

    Only on steps you have marked safe. Anything sensitive pauses for approval.

    Which tools can it use?

    Email, calendar, CRM, docs, chat, databases and 120+ more through connectors.

    Can we run it on our own servers?

    Yes. Enterprise plans include on-premise connectors.

    How long does setup take?

    Most teams connect their first tools and run a task in under an hour.
