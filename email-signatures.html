How to add it

  1. Gmail (on a computer): Settings (gear) → See all settings → General → Signature → Create new. Paste with ⌘ + V, then click Save Changes at the bottom of the page.
  2. Apple Mail (Mac): Mail → Settings → Signatures → +. Untick “Always match my default message font”, paste, then close the window.
  3. iPhone Mail: it doesn't keep formatting. Set it up in Gmail or Apple Mail on the Mac instead.

The logo and signature images load from zimansites.com, so they appear for everyone you email once the site update with these images has been uploaded.
